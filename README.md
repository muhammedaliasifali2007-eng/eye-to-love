# Eye to Love — Procedural ASCII Shader

A full-screen procedural colored ASCII shader animation where a realistic human eye opens, looks around, blinks, and zooms through its pupil into a 3D cross-flare starfield and a glowing, beating **3D Red Love Heart**.

## Files
- **`eye_to_love.html`** — Standalone fullscreen HTML file (open directly in any browser).
- **`eye_to_love.py`** — Standalone Python + NumPy + Tkinter desktop script for Visual Studio Code (`python eye_to_love.py`).

## Controls
- **`Space`** : Pause / Play
- **`R`** : Restart from `0.0s`
- **`F`** or **Double-Click** : Toggle Fullscreen (in `eye_to_love.html`)
- **`Esc`** : Quit window (in `eye_to_love.py`)
