# Eye to Love — Procedural ASCII Shader

A procedural colored ASCII shader animation where a realistic human eye opens, looks around, blinks, and zooms through its pupil into a 3D cross-flare starfield and a glowing, beating **3D Red Love Heart**.

## Repository Contents
- **`eye_to_love.html`** — Standalone, edge-to-edge fullscreen HTML5 version (runs in any web browser with zero external dependencies).
- **`eye_to_love.py`** — Standalone 100% pure standard-library Python + Tkinter desktop script for Visual Studio Code (no `numpy`, `pillow`, or `pip install` required).

---

## How to Run

### 1. Web Browser (`eye_to_love.html`)
Double-click **`eye_to_love.html`** to open it in any browser (Chrome, Edge, Firefox, Safari), or open it via **GitHub Pages**.
- **`Space`** : Pause / Play
- **`R`** : Restart from `0.0s`
- **`F`** or **Double-Click** : Toggle Fullscreen
- **Hover bottom-right** : Interactive timeline scrubber

### 2. Visual Studio Code / Python (`eye_to_love.py`)
Open **`eye_to_love.py`** in **VS Code** and press **Run (`F5` or ▷)**, or run in terminal:
```bash
python eye_to_love.py
```
- **`Space`** : Pause / Play
- **`R`** : Restart from `0.0s`
- **`Esc`** : Close window
